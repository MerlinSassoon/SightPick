## C. 仍需你确认的假设

1. **滚动距离单位**：原型将配置值视为 `pyautogui.scroll` 的滚轮档位，而不是像素。请用 `python run.py scroll-test` 验证。
2. **前端窗口识别**：浏览器标签页标题只是标签名，无法用 `Streamlit` 关键字可靠匹配；前端默认走“倒计时模式”，若要用“自动最小化”，请通过启动器注入 `?page=<标签名>` 并选择“API 模式”（或前端运行在独立应用窗口中时使用标题关键字）。
3. **DeepSeek 模型名**：默认 `deepseek-flash`（官方视觉文档），可通过计划 `run.llm_model` / `.env` 修改。
4. **点击锚点**：默认点击区域内最上方 OCR 文本行的中心；如列表首行是头像/标签，请配置 `click_anchor`。
5. **字典模式重复键**：默认合并描述；如果你希望“同标题岗位分开存储”，需要改为列表结构（当前 JSONL 已逐条保存，不受字典合并影响）。
6. **公司/薪资**：附录 A 才规划公司信息采集；当前可额外框一个区域并通过 `output.extra_fields` 映射，否则为 `null`。
7. **展示尺寸**：默认上限 1280×800（约 1920×1080 的 0.67×，误差 ≤ 1.5 原图像素）；若需要像素级精修，可在前端把上限调大或直接编辑区域坐标。
