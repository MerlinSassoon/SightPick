# 真实页面运行手册（RUNBOOK）

> **2026-10-23 更新**：项目定位已调整为“视觉 RPA 工程样品”，当前以 BOSS直聘为案例。
>
> 真实运行证据见 [EVIDENCE.md](EVIDENCE.md)，页面结构/已知问题见 [CASE_BOSS.md](CASE_BOSS.md)。
>
> 运行前请阅读 [PRIVACY.md](PRIVACY.md)：`runtime/` 含真实截图与招聘者信息，不可上传。
>
> 以下命令默认在仓库根目录执行。

本手册面向在 Windows 桌面上对 BOSS直聘 等招聘页面执行真实采集。**先跑 mock demo 确认安装与输出格式，再做真实运行。**

## 1. 前置条件

- Windows 10/11，桌面会话（不是远程无头会话）；
- Python 3.10+；
- 屏幕分辨率与缩放比例在两次运行间保持一致（示例配置为 1920×1080、100%）；
- 浏览器已登录目标网站，岗位列表与详情页面可见；
- DeepSeek API Key（`DEEPSEEK_API_KEY`）；
- 目标网站的使用条款允许此类个人研究用途。

## 2. 安装与自检

```powershell
# 在仓库根目录执行
python -m pip install -r requirements.txt
python run.py demo
python -m pytest -q
```

`demo` 应为 3 个岗位、`stop_reason=list_end`，且 `jobs.jsonl` 无重复行、无“去App”等噪声。

PaddleOCR 首次真实识别会下载模型，请留出时间与磁盘空间。

## 3. 启动前端

```powershell
streamlit run app/streamlit_app.py
```

如果提示缺少组件：

```powershell
python -m pip install streamlit streamlit-image-coordinates
```

## 4. 截图与框选

1. 在浏览器打开目标岗位页面（个人推荐/搜索列表 + 右侧详情）。
2. 回到 Streamlit 页面 → “① 截图与框选” → 选择**窗口处理方式**：
   - **倒计时模式（默认，推荐）**：设置倒计时秒数（默认 5）→ 点“截取首屏”→ 立即切到目标页面并最大化浏览器；
     倒计时结束后程序不会最小化或激活任何窗口，只做固定 3 秒稳定等待后截图。
   - **自动最小化前端窗口**：仅当前端运行在独立应用窗口（如 pywebview/Electron 壳）时使用。
     程序只最小化“本服务进程所属且标题匹配”的窗口，截图后后台恢复（不抢焦点）；
     **定位不到就什么都不做**，绝不会去最小化命令行或其它任意窗口（历史上正是前台回退导致命令行被影响）。
     可用 `python scripts/window_diag.py --monitor 15` 在一个命令行窗口里旁路确认前台窗口没有被干扰。
3. 在截图预览中框选三个区域（以 1920×1080 的 BOSS 页面为例，仅作参考）。预览图会等比缩放到一屏内，
   **框选自动换算回原图像素坐标**，因此可以框到页面任意边缘：

| 区域 | 参考坐标 | 内容 | 模式 |
| --- | --- | --- | --- |
| A | `[212, 300, 620, 930]` | 左侧岗位列表 | 短信模式 |
| B | `[660, 440, 1460, 930]` | 职位描述及以下 | 抄录模式（可滚动） |
| C | `[660, 330, 1460, 430]` | 岗位标题/薪资/标签 | 抄录模式（不滚动） |

框选后可在区域表中直接修改数字。删除区域后新增会复用最小未用编号。

> DPI 缩放会导致坐标偏移。请确保桌面前后一致；运行前程序会比对屏幕尺寸，不一致默认中止（`on_screen_change=abort`）。

## 5. 区域配置

进入“② 区域配置”，或点击“加载示例配置”后按实际页面调整：

**区域 A（短信模式）**

- 滚动距离：建议先用滚动测试确定（示例 -210）；
- 滚动起始坐标：列表内一点，如 `410, 380`；
- 停止条件：`企业服务, 使用与帮助`（列表页脚；默认按“包含”匹配）；
- 调用区域：先选 `C` 再选 `B`；
- 文本数据结构：字典模式；
- 做键区域：`C`（必须是字符串格式）；
- 份数上限：例如 20；
- 点击确认：默认关闭；若经常点错，开启后再运行（会产生额外大模型调用与回滚）。

**区域 B（抄录模式，可滚动）**

- 可滚动：是；
- 滚动距离：示例 -180；
- 滚动起始坐标：描述区域左下角，如 `700, 900`；
- 停止条件：`工作地址, 去App, 先生`；
- 期望内容：`职位描述`；
- 期望格式：`list`；
- 首轮锚点：`职位描述`；
- 最大轮次：12；
- 每轮去噪：关闭（默认只在最后调用一次，控制成本）。

**区域 C（抄录模式，不滚动）**

- 可滚动：否；
- 期望内容：`岗位名称`；
- 期望格式：`str`。

最后在“输出映射”中选择标题区域 `C`、描述区域 `B`。

## 6. 滚动测试（FR-04）

1. 打开“③ 滚动测试”，选择区域；
2. 填入 `x / y / 距离 / 次数 / 间隔`，倒计时建议 3 秒；
3. 点击“开始滚动测试”，**立即切换到目标页面**，不要触碰鼠标键盘；
4. 观察日志与页面：两次滚动之间首尾应有重叠、无缺漏；
5. 把验证后的数值填回区域配置。

急停：把鼠标快速移到屏幕左上角，pyautogui 会抛 `FailSafeException`，程序中止并保留已落盘数据。

## 7. 真实运行

推荐从命令行启动（日志最完整）：

```powershell
$env:DEEPSEEK_API_KEY = "sk-..."
python run.py validate --plan configs/boss_1080p_example.json
python run.py run --plan configs/boss_1080p_example.json
```

或在前端“④ 运行采集”中：

- 引擎选 `real`，大模型选 `deepseek`；
- 设置份数上限与倒计时；
- 点击“启动采集”；
- 运行期间查看 `run.log` 与已落盘条数。

启动后程序会：

1. 校验计划与屏幕尺寸；
2. 可选最小化前端；
3. 倒计时（默认 5 秒）后开始点击、截图、OCR、大模型确认；
4. 每采集一条岗位立即写入 `runtime/runs/<id>/jobs.jsonl`；
5. 结束时写 `jobs.json`、`capture_report.json`，并在列表到底时提示人工核对最后几项。

## 8. 停止、恢复与人工补录

- 正常停止：达到份数上限，或命中列表停止条件；
- 异常停止：查看 `run.log` 与 `capture_report.json`；`jobs.jsonl` 已保留；
- 恢复：程序目前不支持断点续采（NEWREADME 未设计），可重新运行并在人工比对后去重；
- 列表末尾的人工补录：按 NEWREADME 6.6 的设计，由人工确认完成。

## 10. 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 首屏截图黑屏/空白 | 远程会话、锁屏、权限 | 使用本机桌面会话；改用倒计时模式重新截图 |
| 截首屏后命令行窗口被前置/干扰 | 旧版本在找不到前端窗口时会回退最小化“当前前台窗口” | 已修复：定位不到就什么都不做；优先使用倒计时模式；可用 `scripts/window_diag.py` 验证 |
| 自动最小化没有生效 | 浏览器标签页标题不含关键字（标题只是标签名） | 使用倒计时模式；或前端带 `?page=<标签名>` 启动后选“API 模式” |
| 框选到的区域和实际位置有偏差 | 使用了旧的展示图，或修改展示尺寸后未重绘 | 重新点击“截取首屏/载入示例截图”；展示尺寸变化会自动重绘并重置框选 |
| 截图显示不全、框不到底部 | 展示上限设置得比屏幕还大 | 调小“展示最大宽度/高度”（默认 1280×800），整张图会等比缩放进一屏 |
| 点击位置偏移 | DPI 缩放、浏览器缩放、分辨率变化 | 重新截屏框选；保持 100% 缩放；检查运行前屏幕校验 |
| 找不到锚点“职位描述” | 区域 B 未包含标题、页面未加载完 | 扩大/上移区域 B；等待页面加载；检查 `anchor_key` |
| 滚动不停止 | 停止标志未进入区域或 OCR 漏识 | 增加停止关键字；调整滚动距离；检查 `scroll_stop_match` |
| 描述缺行/重复 | 滚动距离过大/过小 | 用滚动测试校准；行级去重已开启 |
| 大模型报错/超时 | 网络、Key、模型名 | 检查 `DEEPSEEK_API_KEY`、`run.llm_model`；失败会降级为纯 OCR 并写 warning |
| 前端帧选组件无拖拽 | 组件版本旧 | 程序自动降级为两次点击框选；或升级 `streamlit-image-coordinates` |
| 前端与目标页互相遮挡 | 同一浏览器窗口 | 使用“倒计时模式”（不做任何窗口操作），或在另一个窗口打开前端 |
| `pip install paddlepaddle` 失败 | 平台/版本不匹配 | 按 PaddlePaddle 官方安装指引选择 CPU 版本 |
| `python run.py` 中文乱码 | 控制台编码 | 使用 Windows Terminal / 设置 UTF-8；文件本身为 UTF-8 |

## 11. 合规提醒

- 仅采集公开可见的岗位信息，用于个人研究与分析；
- 控制频率，避免对目标网站造成压力；
- 不绕过登录、验证码或其他访问控制；
- 不采集招聘者个人隐私；
- 如网站条款禁止自动化访问，请停止使用。
